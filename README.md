# RK Creation Store Sales Analysis

## Project Overview
This project focuses on analyzing sales and order data of RK Creation Store using Microsoft Excel and Power BI. The analysis helps understand sales performance, customer purchasing patterns, order status, sales channels, and regional performance.

## Tools Used
- Microsoft Excel
- Power BI
- Pivot Tables
- Data Analysis
- Data Visualization

## Key Analysis
- Monthly sales and order analysis
- Sales analysis by gender
- Customer age-group analysis
- Order status analysis
- Top-performing states based on sales
- Sales channel analysis
- Product and category performance

## Objective
The objective of this project is to analyze raw sales data and generate meaningful business insights using data analysis and visualization techniques.
